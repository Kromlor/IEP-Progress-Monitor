# IEP Progress Monitor

A fill-in IEP progress monitoring form laid out like the PowerSchool Special Programs (TIENET) progress report page.

- Open it in **Chrome or Edge**.
- Click **Choose caseload folder** and pick your synced SharePoint caseload folder. Each student is saved into their own student folder as `Initials Progress Monitor.json`.
- Supports multiple goals per student, progress code menus, measurable data with formatting and images, and printing.

**No student data is stored in this repository or on the hosted page.** All data is saved only to the folder you choose on your own computer.
